# Complete NGAP-PDU native interoperability qualification

This is a finite, source-pinned **complete-PDU** campaign for all 131 frozen
message identities (81 initiating, 32 successful, 18 unsuccessful), not a
syntax-only scan or generated roundtrip. All six authoritative ASN.1 modules
are used unchanged; their Git blob and SHA-256 identities are checked before
both the independent reference and actual Parser/Fixer extraction.

The native reference is pycrate **0.7.11**, freshly compiled from those six
modules. Each message has mandatory-row minimum and nonzero contrast values;
each additional declared **top-level** IE row has a separate added-row value.
Nested tables select legal mandatory/minimum rows, not every nested table row.
All received criticalities are exercised and distinguished from the declared
policy. Conditional IE requirements and application procedure state are not
qualified. PrivateMessage uses explicit local/global unknown raw entries in
its empty private object set; this is owned transparent framing, not vendor
payload interpretation. CONTAINING transfer values are natively constructed
to obtain legal bytes, but the generated parent stores them as opaque octets.

The low/contrast profiles preserve collection minimum lengths. They vary
integers to retained root endpoints, BOOLEAN, ENUMERATED, CHOICE, patterned
BIT/OCTET/character values and constructible ordinary root OPTIONAL fields.
They do not exhaust sizes, every CHOICE path, known additions or extension
value space. Existing component qualification retains those separate limits.

## Reproduce

Build the current tree's parser, fixer and typed libraries before the tools
(the historical top-level subdirectory dependency order is unchanged):

```sh
make -C libasn1parser
make -C libasn1fix
make -C libasn1typed
make -C tools asn1typed_full_pdu_probe asn1typed_ioc_probe
python3 -m pip install -r tools/full-pdu-qualification/requirements.txt
python3 tools/full-pdu-qualification/qualify.py \
  --repo . --asn1-root /path/to/frozen-source-root \
  --probe tools/asn1typed_full_pdu_probe \
  --work /path/to/new-empty-work-directory \
  --accepted-profile tools/full-pdu-qualification/accepted-profile.json \
  --output /path/to/replay-summary.json --jobs 1
```

The work directory must not exist. Sequential compilation is the default:
large generated messages can exhaust memory when compiled concurrently.
The runner pins the reference version, verifies exact identities and roles,
requires deterministic generation of all six headers after Parser deletion,
strictly compiles and executes 131 standalone C++ programs with assertions
independent of NDEBUG, and native-backdecodes the **actual generated bytes**.
Every case constructs a new typed value independently, compares complete bytes
including length, and checks all selected decoded fields, optional presence,
list order/count, wrapper types, payloads and empty extension sidecars.

The per-message physical campaign uses a mandatory-minimum case, independently
derived envelope padding/selector/determinant/trailing errors and every short
byte prefix. Exact/insufficient input/output/wire budgets, known-payload failure
without opaque fallback, and copy/move ownership are checked. It is not every
inner field mutation or every per-case resource boundary.

The work directory retains generated native code, 786 headers, C++ TUs,
compiler logs, actual encoded case outputs and candidate profile. Without
`--accepted-profile`, success is explicitly a matched **candidate**, requiring
independent review. A changed reviewed profile is rejected. Failures do not
leave a previous output PASS. Source/input stability guards prevent publishing
results from changing code. Do not replace expected bytes or accept a profile
merely to hide a disagreement.

Historical N11 exact-profile replay remains separate; it covers receive-only
unknown root/CHOICE/IE behavior and recorded inherited reference exceptions.
Its 72 inherited native BODY-fragment exceptions are not counted as new full
native semantic agreements. The new profile requires actual exact native
backdecode for each of its own cases, without repair or suppression.

No live vendor, NAS/RRC inner protocol, exhaustive ASN.1 conformance or
benchmark result is claimed by this campaign.
