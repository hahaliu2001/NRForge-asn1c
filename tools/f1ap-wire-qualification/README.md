# F1-P4 finite independent complete-PDU qualification

This campaign uses pycrate 0.7.11 freshly compiled from the six unchanged frozen
F1AP modules, and the actual generated public registry plus typed BODY codecs.
It does not reuse an installed F1AP release or use same-codec roundtrips as the
oracle. Scope and promotion rules:
[`docs/f1ap-cpp-aper-wire-qualification-contract.md`](../../docs/f1ap-cpp-aper-wire-qualification-contract.md).

Install the pinned `requirements.txt` in your task environment. A scratch
`--target` installation is also supported by setting `PYTHONPATH` to that target.
First generate and build the complete F1AP library and run
`tools/f1ap-readiness/check_dispatch.py` as documented in the readiness README.
That actual all-slot integration receipt attests the archive and its inputs;
the qualifier refuses a changed archive or changed attested production inputs.
For the unchanged F1-P3 baseline, its committed receipt can attest the original
archive with the recorded exact SHA-256. A rebuilt or fixed archive needs a new
actual linked integration receipt, not an edited historical report.

```sh
python tools/f1ap-wire-qualification/qualify.py \
  --asn1-root /path/to/NRForge-RAN/src \
  --generated-root /path/to/generated-f1ap \
  --archive /path/to/build/libnrforge_f1ap.a \
  --archive-receipt /path/to/actual-all-slot-integration.json \
  --work /tmp/new-f1ap-wire-campaign \
  --output /tmp/f1ap-wire-candidate.json --jobs 1
```

The work path must not exist. The output of a failed rerun is removed before
validation so it cannot retain stale PASS. All 158 unique message identities,
94 procedures, declared criticalities, native tags and actual registry source
declarations must agree. The public-only test TUs are strict C++20 with real ELF
object validation. GNU gold links them with the attested complete library;
mapping/output memory options are recorded. Avoid concurrent large links under
a constrained memory budget. `--jobs 1..4` changes only public-TU compilation,
not oracle construction or semantic coverage.

Native low/contrast values populate legal mandatory/minimum IE rows and every
additional declared top-level row, with all three received criticalities.
Selected SRBID paths also exercise extension-union values 4 and 5. Expected C++
objects and field assertions are constructed from native semantic values, not
decoded generated bytes. Each complete generated byte vector must equal the
native vector exactly; actual generated bytes are natively backdecoded and
compared to the original complete semantics. Traces identify actual selected
rows, primitives, CHOICE alternatives and unconstructible omitted optionals.
No byte normalization or suppressed reference mismatch is permitted.

One baseline per identity exercises prefix/padding/determinant/trailing errors,
input/output/wire budgets, malformed-known refusal and owned copies/moves after
input damage. Every actual unknown procedure code and absent known outcome is
separately tested as receive-only opaque, with retention limits and encode
refusal. The fourth root is unsupported and rejected at physical bit 2; that
negative policy is not qualification of its payload semantics.

The runner publishes a matched candidate, not an automatically accepted profile.
After independent review, promote the exact logical candidate without altering
case, wire, semantic or source fingerprints. The committed `accepted-profile.json`
is a lossless gzip/base64 transport envelope to keep repository/API transport
within its request limit. Its decompressed payload is the exact approved original
JSON, including its historical candidate status. Storage and logical profile
hashes are distinguished in `qualification-summary.json`. Restore it before
passing `--accepted-profile`; the existing runner expects the expanded original:

```sh
python - <<'PY'
import base64, gzip, hashlib, json
from pathlib import Path
envelope = json.loads(Path('tools/f1ap-wire-qualification/accepted-profile.json').read_text())
assert envelope['format'] == 'nrforge-f1ap-lossless-profile-envelope-v1'
payload = gzip.decompress(base64.b64decode(envelope['data'], validate=True))
assert len(payload) == envelope['profile_bytes']
assert hashlib.sha256(payload).hexdigest() == envelope['profile_sha256']
Path('/tmp/f1ap-accepted-profile.json').write_bytes(payload)
PY
```

`--accepted-profile /tmp/f1ap-accepted-profile.json` checks future replay against
the reviewed original profile. Full byte vectors, semantic hashes, coverage
traces, actual executable/TU/object hashes, compiler/link options and source
fingerprints are retained. No vectors are removed or reserialized by this storage
format. Historical P1/P2/P3 and NGAP wire profiles stay intact.

Acceptance is finite: no exhaustive size/fragmentation/nesting/combination,
extension/vendor, mandatory-IE procedure policy, application-condition,
contained RRC/NAS, state-machine or live-vendor interoperability claim. No
benchmark is run. Installed F1AP C++/Python SDK delivery remains F1-P5/F1-P6.
