# N17 generated inline ENUMERATED qualification

```sh
python tools/n17-shape-qualification/qualify.py --build /path/to/build --output tools/n17-shape-qualification/qualification-summary.json
```

Requires pinned `asn1tools==0.167.0` and C++20. The build must contain `check_asn1typed_shape_render`; it parses/fixes the actual `shape-generation-n17.asn1` fixture, deletes the parser tree, and renders types/mapping/codec headers. Alternatively `--generated` accepts retained headers generated with namespace `shaperef`.

This tool compiles and executes those actual generated complete codecs. It independently compiles the same fixture's `ShapeGeneration` module with native aligned PER and implements a separate Python bit model. It compares complete bytes, generated decoding of native bytes and every field's assigned enum number/presence, then native decoding of generated bytes and complete ASN.1 field semantics. No runtime-only stand-in or handwritten replacement codec is used.

The 240 cases combine all three root `phase` values, absent/all four known root/addition `status` values, absent/all three `copy` values, both keyword-named `class` values, and direct `Panel` versus nested `Envelope` encodings. The latter includes a CHOICE-contained Panel and a bounded one-element collection of Panel, exercising different field offsets, optional bitmaps and payload alignment. The root enum's numeric source order differs from PER numeric order; addition assigned numbers differ from root ordinals. Expected model bits use assigned numeric semantics and canonical PER indexes independently.

Source/runtime/fixture/renderer hashes are captured before execution and verified unchanged before publishing. Summary includes generated header hashes, compiler version and strict flags. This is bounded known-value generated-shape qualification; unknown additions, malformed input, all NGAP schemas and complete PDUs are outside this report.
