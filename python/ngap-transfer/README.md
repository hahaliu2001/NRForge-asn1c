# NRForge NGAP Python 0.2.0

Installed-SDK wheel profile for the original 131 outer PDUs and four independent
Transfer roots. Build using tools/ngap-transfer-sdk/build_delivery.py under its
resource guard. Shared F1AP/E1AP and legacy 0.1.0 source staging remain separate.
Only wheel builds from the full committed source snapshot are supported here;
this profile does not declare a standalone source-distribution deliverable.
