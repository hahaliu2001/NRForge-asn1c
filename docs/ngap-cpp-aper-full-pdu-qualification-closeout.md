## Independent relations actually executed

The independent reference is pycrate **0.7.11**, freshly compiled from the six
unchanged TS 38.413 V18.10.0 modules. Native/source/probe role, procedure-code,
criticality and message registries agree. Every case constructs a fresh typed
value from independently supplied native semantics, compares the entire encoded
byte vector and length, then native-backdecodes the **actual generated bytes**.
Native complete PDUs are decoded by generated codecs and all selected fields,
presence states, list order/count, primitive values, CHOICE wrappers, received
criticality, typed IE payloads and empty extension sidecars are checked.
Generated roundtrip agreement alone is not used as an oracle.

All three received-criticality values retain known typed dispatch, distinct from
schema-declared criticality. Mandatory/minimum top-level IE rows and each
additional declared top-level row have recorded low/contrast values. Nested
rows use constructible legal mandatory/minimum values; the trace is the actual
selection, not proof of every nested row or every combination. The largest
complete PDU in this profile is **427 octets**. Thus full-message fragmentation
at large lengths is not newly qualified by these values.

One mandatory-minimum case per message exercises every short-byte prefix,
selected envelope selector/criticality/alignment/determinant errors and trailing
bytes; exact/insufficient input, output and wire budgets; copied/moved owned
decoded values after input damage; and malformed known payloads without an opaque
fallback. This is a finite mutation matrix, not exhaustive inner-field mutation
or malformed-input error-priority coverage. An independent framing reviewer also
ran 90 valid and 2,349 negative model-only checks and killed four targeted C++
mutations. Those checks are not added to the 7,315 production count.

strict build, pinned reference and accepted-profile gate. The probe, runner,
semantic bridge, native constructor, independent framing model, profile,

patterned BIT/OCTET/string values and constructible root OPTIONAL fields while
keeping collection lengths at legal minima. Unconstructible optional selections
are omitted/recorded, not silently called covered. No exhaustive extension,

object set, not typed vendor payload interpretation. NAS/RRC behavior, procedure
policy, live equipment differential, performance and benchmarks remain outside
